## 🛠️ WEEKLY PRACTICE QUESTS (SKILL CHECK)
*Complete these every Friday to prove you've mastered the week's material.*

### 🏆 Week 1: The "Digital Vault" (Basics)
*   **Goal**: Create a script `quests/week_1_vault.py`.
*   **Tasks**: 
    1.  Create a dictionary `user_data` that stores a username and a list of "secrets" (strings).
    2.  Write logic to add a new secret to the list.
    3.  Format the output using f-strings to say: `User [Name] has [X] secrets stored.`
    4.  Implement string slicing to show only the first 3 characters of each secret for security.

### 🏆 Week 2: The "Smart Calculator" (Logic & Modules)
*   **Goal**: Create a module `quests/math_engine.py` and a main script `quests/week_2_calc.py`.
*   **Tasks**:
    1.  The module should have functions for `add`, `multiply`, and `power_of`.
    2.  The main script should import the module.
    3.  Use a `while` loop to keep the calculator running until the user types "exit".
    4.  Use `if/else` to handle different operations.

### 🏆 Week 3: The "Matrix Architect" (OOP)
*   **Goal**: Create a file `quests/week_3_matrix.py`.
*   **Tasks**:
    1.  Define a class `Matrix`.
    2.  Initialize it with a nested list (2D array).
    3.  Create a method `display()` that prints the matrix in a readable grid.
    4.  Create a method `transpose()` that returns a new Matrix object with rows and columns swapped.
    5.  Use a **Special Method** (`__str__`) to print the matrix dimensions.

### 🏆 Week 4: The "Robust Verifier" (Error Handling & Regex)
*   **Goal**: Create a file `quests/week_4_verifier.py`.
*   **Tasks**:
    1.  Build a class `DataCleaner`.
    2.  Use `Regex` to find and extract all email addresses from a messy block of text.
    3.  Use `try/except` to handle cases where the text is empty or not a string.
    4.  **Verification**: Write a function that checks if the extracted emails end in `.com` or `.org`. Report how many passed the "verification."
